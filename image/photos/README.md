# 写真の追加

このフォルダーに JPG / JPEG / PNG / WebP / AVIF / GIF を置くだけで掲載されます。
サブフォルダーも対象です。写真を削除すれば一覧からも消えます。
画像は再圧縮せず、そのまま表示します。

- 公開サイト: 写真をリポジトリに追加して push すると、Pages のビルド時に一覧を自動生成します。
- ローカル: `./serve.sh` で起動すると、開いている `/photos/` に追加・削除が約5秒で反映されます。
- `python3 -m http.server` などフォルダー一覧を表示できるローカルサーバーでも、実ファイルを自動検出します。
- フォルダー一覧を提供しない静的サーバーでは `python3 scripts/photo_catalog.py` で一覧を更新できます。

`photos/data.json` は自動生成されます。手動登録は不要です。
必要な場合だけ `alt`（写真の説明）や `caption`（表示文）を編集できます。
同じファイル名の写真については次回生成時にも引き継ぎます。
一覧を編集しなくても、実ファイルが削除された写真は約5秒で表示から除外します。
これはLive Serverなどのローカル表示でも公開ページでも有効です。
公開サイトの削除反映には、削除をpushしてPagesのビルドを完了させる必要があります。

写真をクリックするとビューアーが開きます。
ホイール・ピンチ・＋/−でズーム、拡大中はドラッグで移動できます。
矢印キー・左右ボタン・通常倍率でのスワイプで写真を切り替え、Esc・×で閉じます。
